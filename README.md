# L3sn1k

GUI-based pentesting toolkit for passive reconnaissance. Built with Java (Swing) and Python.

>  For educational purposes and authorized assessments only.

## Current Features

- Subdomain enumeration via [crt.sh](https://crt.sh) (Certificate Transparency logs)

## Requirements

- Java 11+
- Python 3.8+
- `pip install requests`

## Usage

```bash
git clone https://github.com/MEMPHIZINHOOO/L3sn1k.git
cd L3sn1k
./init.sh
```
